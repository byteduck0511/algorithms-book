# 蓝图（Blueprint）

```markdown
书名：数据结构与算法自学：从工程直觉到复杂度思维
领域：计算机科学 / 数据结构与算法
受众：26 岁软件工程师，大专学历，有 1–3 年编程工作经验，
      会写循环、函数、类，但没有系统学习过数据结构与算法。
先修：
  - 编程：变量、分支、循环、函数、类、数组、List<T> 的基本使用
  - 工具：能运行 dotnet run，或用任意语言对照伪代码阅读
  - 数学：四则运算、乘方、对数概念（log 是什么）、求和符号 Σ 的读法
        —— 不要求微积分、不要求概率论、不要求线性代数
目标：学完后，读者能够
  G1 用大 O 记法分析自己写的代码，指出瓶颈所在
  G2 从零实现常见数据结构（动态数组、链表、栈、队列、哈希表、堆、BST、图）
  G3 独立写出并调通排序、查找、遍历、最短路、DP 等经典算法
  G4 在工作中根据场景选择正确的数据结构，并说清取舍理由
  G5 读懂技术文档与面试题中的算法术语，不再"看得懂字、看不懂话"
深度：中级（覆盖本科 DS&A 核心内容，砍掉严格证明与冷门结构）
总字数：约 19.6 万中文字（正文，不含代码块），63 节
章节数：7 个部分 / 16 章 / 63 节
每节字数：1,500–6,400 中文字（不含代码块），平均约 3,100 字
必须包含：
  - 每节：目标卡、直觉、形式化、例题、可运行 C# 代码或伪代码、3–5 题练习、
    答案（含关键步骤）、常见错误、状态外显 JSON
  - 全书：统一术语表、符号表、索引、术语总表、学习路径时间线、审校报告
必须避免：
  - 无规划直接写正文
  - 术语漂移（同一概念多个名字）
  - 跳步（"显然可得"式省略）
  - 无答案练习
  - 不可运行的代码
  - 一次生成全书
假设：
  A1 读者已掌握基础编程语法，不需要从"什么是变量"讲起
  A2 读者可安装 .NET SDK 8；不能安装时使用伪代码路径
  A3 不涉及具体框架（ASP.NET / Unity / WPF）的算法应用
  A4 学习节奏为 16 周，每周 1 章、约 4 节、4–6 小时

## 与技能默认值的偏离声明

| 项 | 技能默认 | 本书实际 | 原因 |
|---|---|---|---|
| 单节字数 | 600–1000 字 | **1,500–6,400 字**（平均 3,111） | 见下 |
| 总字数 | — | 约 19.6 万字 | 63 节 × 平均字数 |

**偏离理由**（已在 `review-report.md` 第三节详细论证，用户已确认采用方案 A）：

1. **练习答案占 35–45%**。技能要求"答案给关键步骤，不只给结果"，而本书的读者是**无监督自学**的工程师 —— 压缩答案等于取消自学的可行性。
2. **25 处反预期实测需要完整分析**。每处都要"现象 → 原因 → 修正结论 → 启示"，无法只给结论。
3. **代码块虽不计入字数，但代码前后的说明必须保留**（为什么这样写、陷阱在哪、输出怎么读）。

**不变的部分**：技能要求的其他所有约束仍然严格遵守 ——
先规划后写作、分节里程碑、状态外显、固定术语、防漂移检查、多轮生成、生成终止条件。
```

## 难度标尺（全书统一）

| 标记 | 含义 | 出现比例目标 |
|---|---|---|
| 入门 | 只需读懂与照做 | 约 25% |
| 中级 | 需要动手实现与调试 | 约 60% |
| 挑战 | 需要自己推导或优化 | 约 15% |

## 代码约定（全书统一）

- 语言：C# 12 / .NET 8，顶级语句或静态方法均可。
- 命名：类与公开方法用 `PascalCase`，局部变量用 `camelCase`，与 .NET 官方风格一致。
- 泛型：数据结构统一写成 `MyStack<T>` 形式，避免为每种类型重写。
- 伪代码：用固定关键字 `过程` / `函数` / `若…则…否则` / `循环…结束` / `返回`。
- 每段代码给出预期输出；无输出的代码给出断言（`Debug.Assert` 或 `if (...) throw`）。
- 不使用 NuGet 第三方包，只用 BCL（`System`, `System.Collections.Generic`）。
